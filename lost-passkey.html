Kode pemulihan siap

Kode sengaja tidak ditampilkan di layar. Tekan tombol di bawah tepat satu kali, lalu segera tempelkan kode pada layanan resmi untuk membuat passkey baru.

Setelah penyalinan berhasil, seluruh buffer dan referensi data pemulihan di halaman ini langsung dibersihkan.

Proses aman

Tautan resmi → validasi akses → wajib offline → isi informasi verifikasi → proses pemulihan → salin kode satu kali tanpa menampilkannya → seluruh data sementara dibersihkan.
